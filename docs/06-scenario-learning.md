# 06 — Scenario Learning

## Purpose
Define contextual speaking practice around realistic situations and measurable learning objectives.

## Scenario Model
A scenario contains: title, context, objective, learner level range, target skills, target vocabulary, difficulty, estimated duration, prerequisites, completion criteria, and safety metadata.

## Progression
Scenarios progress from familiar/high-support contexts to varied and lower-support contexts. Difficulty may change vocabulary, grammar, ambiguity, speaking speed, turn complexity, or required independence.

## Session Structure
Brief setup → teacher opening → learner turns → adaptive support/correction → objective completion → summary → recommended review.

## Personalization
Selection considers level, goals, interests, recent errors, weak vocabulary, previous scenarios, performance, and preferred session length. Repetition should be intentional, not accidental.

## Scenario Types
Examples include introductions, travel, shopping, workplace communication, study, appointments, social conversation, problem solving, and opinion exchange. Safety-sensitive scenarios require appropriate boundaries.

## Completion
A scenario is complete when its objective is reasonably demonstrated or the learner exits. Completion must not imply mastery; mastery belongs to assessment logic.

## Acceptance Criteria
- Every scenario has a clear objective.
- Difficulty is explicit and adjustable.
- Practice produces reusable learning signals.
- Repetition and recommendations use learner history.
- Scenario content is versioned and reviewable.
